# 3Ddevelop

초보자도 쉽게 쓸 수 있는 크리에이티브 프로그램 제품군 **바코 스튜디오**입니다.
어도비 제품군처럼 용도가 다른 여러 프로그램이 같은 디자인과 같은 AI 도우미를 함께 씁니다.

| 프로그램 | 하는 일 |
| --- | --- |
| **바코 스튜디오 허브** | 제품군 프로그램을 설치하고, 열고, 업데이트하는 곳. AI 키도 여기서 한 번만 넣어요 |
| **바코 빙산** | 3D 모델 만들기, 로블록스로 내보내기 |
| **바코 눈꽃** | 에이스프라이트식 픽셀 아트: 레이어 × 프레임 타임라인, 양파 껍질, 선택 도구, 팔레트, GIF·스프라이트 시트 |
| **바코 진주** | 포토샵식 사진 편집: 레이어·혼합 모드·마스크, 보정 레이어(레벨, 곡선 …), 선택 도구, 브러시·복제 도장, 필터 |
| **바코 파도** | 오디션식 파형 편집: 효과 랙 (EQ, 컴프레서, 리버브), 라우드니스, 노이즈 줄이기, 스펙트럼 상자 지우기/메우기 |
| **바코 오로라** | 프리미어 프로식 영상 편집: 여러 트랙 타임라인, 효과 컨트롤과 키프레임, 색 보정, 글자, MP4 내보내기 |

## 폴더 구조

```
apps/
  hub/            바코 스튜디오 허브 (프로그램 설치·실행·업데이트)
  modeler/        바코 빙산 (Electron + React + three.js)
  pixel/          바코 눈꽃 (Electron + React + Canvas)
  photo/          바코 진주 (Electron + React + Canvas)
  sound/          바코 파도 (Electron + React + Web Audio)
  video/          바코 오로라 (Electron + React + Canvas + MediaRecorder)
packages/
  shell/          모든 앱 공통 Electron 기반: 창 만들기, 화면과 메인 프로세스 연결, AI 요청 통로
  ui/             모든 앱 공통 화면 디자인: 테마, 메뉴 막대, 도구 막대, 패널, AI 도우미 패널
```

새 프로그램(예: 바코 진주)은 `apps/` 아래에 폴더를 하나 더 만들고 `@suite/shell` 과 `@suite/ui` 를 가져다 쓰면 됩니다.
허브에 보이게 하려면 `apps/hub/src/catalog.ts` 에 넣고, `.github/workflows/build.yml` 의 목록에 추가해요.
제품군 이름은 `packages/ui/src/brand.ts` 한 곳에서 바꿀 수 있습니다.

## 설치 파일로 설치하기 (가장 쉬움)

1. [Releases](https://github.com/RealSalmon12/3Ddevelop/releases/latest) 에서 `BacoStudio-Setup-….exe`(**바코 스튜디오 허브**)를 받아 실행해요.
2. 허브를 열면 프로그램 목록이 나와요. 원하는 프로그램의 **설치**를 누르고, 다 되면 **열기**를 눌러요.
3. 오른쪽 **✨ AI 도우미** 칸에 API 키를 한 번 넣으면 모든 프로그램에서 AI 를 쓸 수 있어요.

허브 없이 프로그램 하나만 받고 싶으면 [모든 릴리스](https://github.com/RealSalmon12/3Ddevelop/releases)에서 `BacoStudio-3D-Modeler-Setup-….exe` 나 `BacoStudio-Pixel-Setup-….exe` 를 받아도 돼요.
코드가 `main` 에 병합될 때마다 GitHub Actions 가 바뀐 프로그램의 설치 파일을 자동으로 만들어 올려요.

> 아직 코드 서명을 하지 않아서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요. **추가 정보 → 실행** 을 누르면 됩니다.

직접 설치 파일을 만들려면 Windows 에서 `npm run dist:hub`, `npm run dist:modeler`, `npm run dist:pixel` 을 실행하세요. 각 앱의 `release/` 폴더에 .exe 가 생겨요.

## 업데이트

설치한 프로그램은 켤 때마다 새 버전이 있는지 확인해요. 있으면 오른쪽 위에 노란 **새 버전** 버튼이 생기고, **지금 업데이트**를 누르면 내려받아 설치한 뒤 새 버전으로 다시 열려요. 저장하지 않은 작업이 있으면 먼저 저장하라고 알려 줘요. **도움말 → 업데이트 확인**으로 직접 확인할 수도 있어요.

이 기능이 들어간 버전은 한 번만 직접 설치하면 되고, 그다음부터는 프로그램 안에서 업데이트돼요.

## Windows 에서 개발 모드로 실행하기

1. [Node.js](https://nodejs.org/) LTS 버전(22 이상)을 설치합니다.
2. 이 폴더에서 명령 프롬프트나 PowerShell 을 열고 한 번만 실행합니다.
   ```
   npm install
   ```
3. 프로그램을 개발 모드로 켭니다. 코드를 고치면 화면이 바로 바뀝니다.
   ```
   npm run dev:hub
   npm run dev:modeler
   npm run dev:pixel
   ```

그 밖의 명령:

| 명령 | 하는 일 |
| --- | --- |
| `npm run build` | 모든 프로그램을 실행 파일로 묶기 전 단계까지 빌드 (`build:hub` 처럼 하나만도 돼요) |
| `npm run typecheck` | 모든 패키지의 TypeScript 타입 검사 |

## 바코 눈꽃 조작법

에이스프라이트 같은 픽셀 아트·애니메이션 편집기예요.

| 조작 | 동작 |
| --- | --- |
| 왼쪽 클릭·끌기 / 오른쪽 | 칠하기 / 지우기 (Shift+클릭: 마지막 점에서 직선) |
| 마우스 휠, Space+끌기 | 확대·축소, 화면 옮기기 |
| B / E / D / G / I | 연필 / 지우개 / 명암 붓 / 채우기 / 스포이트 |
| N / T | 그라디언트 (오른쪽 끌기: 투명으로) / 글자 |
| L / U / O | 직선 / 네모 / 동그라미 (Shift: 45도·정사각형·정원) |
| M / W / V | 네모 선택 / 자동 선택 / 옮기기 (Shift: 더하기, Alt: 빼기) |
| Ctrl+A / Ctrl+D / Ctrl+Shift+I | 모두 고르기 / 풀기 / 반전 |
| Ctrl+C / X / V, Delete, 방향키 | 복사 / 잘라내기 / 붙여넣기, 지우기, 한 칸씩 옮기기 |
| [ ] / X | 붓 크기 / 전경색↔배경색 |
| , / . / Enter | 이전·다음 프레임 / 재생 |
| Alt+N / Alt+D | 새 빈 프레임 / 지금 프레임 복사 |
| Shift+N / Ctrl+E | 새 레이어 / 아래 레이어와 합치기 |
| Shift+M / Shift+T / Shift+O | 대칭 바꾸기 / 타일 모드 / 양파 껍질 |
| Ctrl+O / Ctrl+S / Ctrl+Shift+E / F3 | 열기 (.npixel, .aseprite) / 저장 (.npixel) / 내보내기 / 기능 검색 |

- **타임라인**: 줄은 레이어(눈, 잠금, 불투명도), 칸은 프레임이에요. 칸마다 작은 그림이 보이고, 프레임 번호를 끌면 순서가 바뀌어요. 프레임마다 시간(ms)을 따로 정할 수 있어요.
- **태그**: 타임라인의 🏷 태그로 ‘걷기’, ‘점프’처럼 프레임 몇 장에 이름을 붙여요. 재생 방향(앞으로, 거꾸로, 왕복)을 정할 수 있고, 태그를 누르면 재생, 미리보기, 스프라이트 시트·GIF 내보내기가 그 태그의 프레임만 써요. 두 번 누르면 고쳐요.
- **그라디언트**: 전경색에서 배경색으로 직선이나 원형으로 칠해요. ‘디더링 무늬’를 켜면 두 색만 써서 바둑판 무늬로 바뀌어 픽셀 아트답게 보여요. 고른 곳이 있으면 그 안에만 칠해요.
- **글자**: 도구 설정에 쓴 글자를 끌어서 자리를 정하고 찍어요. 크기와 굵게를 고를 수 있어요.
- **양파 껍질**: 앞 프레임은 빨갛게, 뒤 프레임은 파랗게 비쳐 보여서 움직임을 그리기 쉬워요.
- **연필 설정**: 픽셀 퍼펙트(꺾인 곳 군더더기 없애기), 디더링(바둑판 무늬), 좌우·위아래·네 방향 대칭.
- **타일 모드**: 그림이 사방으로 이어져 보이고, 끝을 넘어 칠하면 반대편에 칠해져요. 로블록스 바닥·벽 텍스처에 좋아요.
- **팔레트**: DB32, PICO-8, Sweetie 16, Endesga 32, 게임보이, 로블록스 색. 그림에서 팔레트 뽑기, 끌어서 순서 바꾸기, .hex/.gpl 불러오기·저장 (Lospec 팔레트 그대로). 팔레트 순서가 명암 붓의 밝기 순서예요. **램프 만들기**를 누르면 전경색으로 어두운 색부터 밝은 색까지 5단계를 만들어 넣어요. 픽셀 아티스트들처럼 어두울수록 파랑 쪽, 밝을수록 노랑 쪽으로 색조를 살짝 돌려서(hue shifting) 탁하지 않은 명암이 나와요.
- **편집**: 외곽선 넣기, 색 바꾸기, 색조·채도·밝기, 팔레트 색으로 맞추기(사진을 픽셀 아트로), 캔버스·그림 크기 바꾸기, 90도 돌리기.
- **에이스프라이트 호환**: Ctrl+O 로 .aseprite/.ase 파일을 열면 레이어(그룹은 풀어서), 프레임 시간, 연결된 셀, 태그, 팔레트가 그대로 들어와요. 파일 → ‘에이스프라이트로 내보내기’로 다시 .aseprite 로 저장할 수 있어서 에이스프라이트 쓰는 친구와 파일을 주고받을 수 있어요.
- **아무 각도로 돌리기 (RotSprite)** (스프라이트 → 아무 각도로 돌리기, Ctrl+Shift+R): 에이스프라이트와 같은 RotSprite 방식이라 15°, 30°, 45° 처럼 비스듬히 돌려도 픽셀 계단이 뭉개지거나 구멍이 나지 않아요. 고른 부분이 있으면 그 부분만, 없으면 그려진 그림의 가운데를 축으로 돌리고, 이 레이어의 모든 프레임을 한 번에 돌릴 수도 있어요.
- **내보내기**: PNG(배율), 스프라이트 시트(가로 한 줄, 정사각형, 로블록스 파티클 플립북 2×2·4×4·8×8), 움직이는 GIF. 스프라이트 시트를 프레임으로 가져올 수도 있어요.
- AI 도우미에게 "빨간 물약 병"처럼 쓰면 지금 레이어·프레임에 그려 줘요.

## 바코 진주 조작법

포토샵처럼 왼쪽 **도구**, 위 **옵션 막대**, 오른쪽 **히스토그램 · 속성 · 레이어**로 되어 있어요. 단축키도 포토샵과 같게 맞췄어요.

| 도구 | 키 | | 도구 | 키 |
| --- | --- | --- | --- | --- |
| 이동 (자유 변형) | V, Ctrl+T | | 브러시 | B |
| 선택 윤곽 (사각형/타원) | M, Shift+M | | 지우개 | E |
| 올가미 | L | | 복제 도장 (Alt+클릭으로 원본) | S |
| 자동 선택 (마술봉) | W | | 페인트 통 / 그레이디언트 | G / Shift+G |
| 자르기 | C | | 글자 / 도형 | T / U |
| 스포이트 | I | | 손 / 돋보기 | H (Space) / Z |
| 스팟 복구 브러시 | J | | 닷지 / 번 / 흐림 / 선명 붓 | O (Alt: 닷지 ↔ 번) |

| 조작 | 동작 |
| --- | --- |
| [ ] · 숫자키 | 붓 크기 · 불투명도 (10%~100%) |
| X · D | 전경색/배경색 바꾸기 · 기본 색 |
| Shift / Alt + 선택 | 선택 영역 더하기 / 빼기 |
| Ctrl+A · Ctrl+D · Ctrl+Shift+I | 모두 선택 · 선택 해제 · 반전 |
| Ctrl+J · Ctrl+Shift+J | 레이어 복제 또는 선택 영역을 새 레이어로 · 잘라서 새 레이어로 |
| Ctrl+Shift+N · Ctrl+E · Ctrl+Shift+E | 새 레이어 · 아래와 병합 · 보이는 레이어 병합 |
| Ctrl+[ ] (Shift: 맨 끝) | 레이어 순서 |
| Ctrl+Alt+G | 클리핑 마스크 만들기 / 풀기 |
| Ctrl+L · Ctrl+M · Ctrl+U · Ctrl+B · Ctrl+I | 레벨 · 곡선 · 색조/채도 · 색상 균형 · 반전 (보정 레이어) |
| Alt+Delete · Ctrl+Delete · Delete | 전경색 · 배경색으로 칠하기 · 지우기 |
| Ctrl+C · Ctrl+X · Ctrl+V | 복사 · 잘라내기 · 붙여넣기 (다른 프로그램의 그림도) |
| Ctrl+0 · Ctrl+1 · Ctrl+ +/- · 휠 | 화면 맞추기 · 100% · 확대/축소 |
| Ctrl+Alt+I · Ctrl+Alt+C | 이미지 크기 · 캔버스 크기 |
| Ctrl+S · Ctrl+O · Ctrl+Shift+Alt+W | 저장(.nphoto) · 열기(.nphoto, PSD, PNG, JPG …) · 내보내기 |
| Shift+F5 | 내용 인식 채우기 (선택한 곳을 주변 그림으로 메우기) |
| F3 | 기능 검색 |

- **레이어**: 혼합 모드 16가지, 불투명도, 잠금, 끌어서 순서 바꾸기, 더블클릭으로 이름 바꾸기, Ctrl+클릭으로 모양대로 선택.
- **마스크 ◐**: 검정으로 칠하면 숨기고 흰색으로 칠하면 다시 보여요. 선택 영역이 있으면 그 부분만 보이는 마스크가 돼요.
- **보정 레이어 ◑**: 밝기/대비, 레벨, 곡선, 색조/채도, 활기, 색상 균형, 흑백, 그레이디언트 맵, 반전, 한계값, 포스터화. 원본은 그대로예요.
- **레이어 스타일 (fx)**: 그림자, 외부 광선, 획(테두리).
- **클리핑 마스크**: 레이어를 바로 아래 레이어 모양 안에만 보이게 해요. 사진을 글자 위에 두고 Ctrl+Alt+G 를 누르면 글자 속에 사진이 들어가요. 보정 레이어도 클리핑하면 바로 아래 레이어에만 걸려요.
- **스팟 복구 브러시 (J)**: 잡티나 전선 위를 칠하고 손을 떼면 주변 색과 결로 자연스럽게 메워요. 원본을 찍을 필요가 없어요.
- **닷지/번 붓 (O)**: 칠한 곳만 밝게, 어둡게, 흐리게, 선명하게 해요. 불투명도를 낮게 두고 여러 번 칠하면 자연스러워요.
- **내용 인식 채우기 (Shift+F5)**: 지우고 싶은 사람, 물건, 글씨를 올가미나 선택 윤곽으로 넉넉하게 둘러싸고 누르면, 주변에서 비슷한 조각을 찾아 무늬와 결까지 이어지게 메워요.
- **펜 도구 (P)**: 포토샵처럼 클릭하면 곧은 점, 끌면 매끄러운 곡선이 생겨요. 처음 점을 누르면 닫히고, Ctrl+끌기로 점을 옮기고, Alt+클릭으로 곡선과 뾰족한 점을 바꿔요. Enter 로 선택 영역이 되고(머리카락 말고 매끈한 물건 오려 내기에 딱이에요), 위 막대에서 브러시 크기와 전경색으로 선 긋기나 채우기를 할 수 있어요.
- **픽셀 유동화** (필터 → 픽셀 유동화, Shift+Ctrl+X): 포토샵처럼 붓으로 그림을 찰흙처럼 다듬어요. 앞으로 밀기(W, 얼굴 윤곽·머리카락), 부풀리기(B, 눈 키우기), 오목하게(S), 돌리기(C, Alt: 반대로), 되돌리기 붓(R). [ ] 로 붓 크기를 바꾸고, 선택 영역이 있으면 그 안만 바뀌어요. 큰 사진도 미리보기는 바로 따라오고, 적용할 때 원래 크기로 계산해요.
- **보정 필터** (필터 메뉴): **표면 흐림**은 눈, 입술, 머리카락 윤곽은 그대로 두고 피부와 하늘만 매끈하게 해요(인물 보정의 기본). **먼지와 스크래치**는 사진의 작은 점, 긁힌 자국, 노이즈를 지워요. **하이 패스**는 윤곽만 남겨서, 레이어를 복제해 걸고 혼합 모드를 오버레이로 두면 깔끔하게 선명해져요.
- **포토샵 PSD**: 포토샵 파일을 레이어째 열고(이름, 위치, 불투명도, 혼합 모드, 숨김, 클리핑), 파일 → ‘포토샵 PSD 로 내보내기’로 레이어를 유지한 채 저장해요. 글자, 도형, 효과는 픽셀로 바뀌고, 보정 레이어는 합친 그림에만 들어가요.
- **필터**: 가우시안 흐림, 동작 흐림, 언샵 마스크, 노이즈, 모자이크, 부드러운 빛 (미리 보면서 조절).
- AI 도우미는 지금 그림을 직접 보고 보정하고 글자를 넣어 줘요. "유튜브 썸네일처럼 만들어줘"처럼 써 보세요.

## 바코 파도 조작법

어도비 오디션 같은 파형 편집기예요. 소리는 32비트 실수로 다뤄서 여러 번 고쳐도 음질이 깎이지 않아요.

| 조작 | 동작 |
| --- | --- |
| Space / L | 재생·멈춤 / 반복 재생 켜기·끄기 |
| R | 커서 자리에 녹음 |
| 파형 끌기 / 클릭 | 부분 고르기 (가장자리를 끌어 고치기, Shift+클릭으로 넓히기) / 커서 놓기 |
| 휠, Shift+휠, 가운데·오른쪽 끌기 | 확대·축소, 옆으로 움직이기 |
| = / - / \ | 확대 / 축소 / 전체 보기 |
| Shift+D | 파형 ↔ 스펙트럼(주파수) 보기 |
| E | 스펙트럼에서 주파수 상자로 고르기 (Delete: 상자 안만 지우기, Shift+H: 앞뒤 소리로 메우기) |
| M, Alt+← / → | 마커 넣기, 이전·다음 마커로 |
| Ctrl+X / C / V | 잘라내기 / 복사 / 끼워 넣기 |
| Ctrl+Shift+V | 섞어 붙여넣기 (겹치기) |
| Delete, Ctrl+T | 지우기, 고른 부분만 남기기 |
| Ctrl+L | 라우드니스 맞추기 (LUFS) |
| Shift+P | 노이즈 지문 잡기 |
| Ctrl+S / Ctrl+Shift+S | WAV 저장 / 내보내기 설정 (16·24·32비트, 샘플 레이트, 모노·스테레오) |
| F3 | 기능 검색 |

- **효과 랙**: 파라메트릭 EQ (점을 끌어 고치는 6밴드, 재생 중 스펙트럼 표시), 컴프레서, 리버브, 딜레이, 코러스, 디스토션, 스테레오/팬, 볼륨을 이어 걸어요. "들으며 고치기"를 켜면 재생하면서 바로 바뀐 소리를 듣고, 마음에 들면 고른 부분에 적용해요. "또렷한 목소리", "라디오", "큰 홀", "로봇" 같은 미리 설정이 있어요.
- **효과 메뉴**: 볼륨, 노멀라이즈, 라우드니스 맞추기 (-14 LUFS 는 유튜브·로블록스 기준), 하드 리미터, 곡선을 고르는 페이드, 템포 바꾸기 (음높이 그대로), 음높이 바꾸기 (길이 그대로), 거꾸로, 위상 뒤집기, DC 제거, 앞뒤 무음 자르기. 설정 창에서 "들어 보기"로 미리 들을 수 있어요.
- **노이즈 줄이기**: 잡음만 있는 부분을 고르고 Shift+P 로 지문을 잡은 뒤, 줄일 부분에 "노이즈 줄이기"를 해요. 노이즈 게이트도 있어요.
- **복원** (노이즈 메뉴): **클릭·팝 지우기**는 LP 판 틱 소리, 입술 쩝 소리, 편집 틈의 딸깍 소리처럼 아주 짧게 튀는 소리를 찾아 앞뒤를 이어 메워요. **클리핑 복원**은 너무 크게 녹음돼 꼭대기가 평평하게 잘린 파형을 곡선으로 되살리고, 0dB 를 넘지 않게 크기를 맞춰요.
- **생성**: 무음, 톤 (사인·네모·톱니·세모), 잡음 (화이트·핑크·브라운), 8비트 게임 효과음.
- 아래 **레벨 미터**로 왼쪽·오른쪽 크기와 최고점을 보고, 오른쪽 **분석**에서 최대·평균·라우드니스를 재요.
- AI 도우미에게 "보물상자 여는 소리"처럼 쓰면 효과음을 만들어 줘요.

### 멀티트랙 (9)

오른쪽 위의 **▤ 멀티트랙** 을 누르거나 9 를 누르면 오디션의 멀티트랙 화면이 열려요 (8: 파형 편집으로 돌아가기). 목소리, 배경 음악, 효과음을 트랙마다 따로 두고 섞어요. 원본 소리는 바뀌지 않아요.

| 조작 | 동작 |
| --- | --- |
| 파일을 트랙 줄에 끌어다 놓기, Ctrl+I | 소리 넣기 (겹치면 빈 트랙으로 내려가요) |
| 조각 끌기 | 옮기기 (위아래로 끌면 다른 트랙으로, 다른 조각 끝과 재생 위치에 착 붙어요) |
| 조각 가장자리 끌기 | 앞뒤 다듬기 |
| 조각 위 모서리의 작은 네모 끌기 | 페이드 인·아웃 |
| Ctrl+K / Ctrl+D / Delete | 재생 위치에서 자르기 / 복제 / 지우기 |
| Alt+← / → | 고른 조각을 10ms 씩 옮기기 |
| 조각 더블클릭 | 파형 편집기에서 열기 |
| Ctrl+S / Ctrl+O | 세션 저장 / 열기 (.bses) |
| Ctrl+Shift+E / Ctrl+Shift+M | 믹스다운을 WAV 로 / 파형 편집기로 |

- 트랙마다 **M**(음소거), **S**(솔로), 볼륨, 팬, 레벨 미터가 있어요.
- 트랙을 고르면 오른쪽에 그 트랙의 **효과 랙**이 나와요. EQ, 컴프레서, 리버브를 트랙마다 따로 걸고 재생하면서 바로 들어요.
- 세션 파일은 디스크에서 불러온 소리의 경로만 적어요. 녹음하거나 파형 편집기에서 보낸 소리는 세션 파일 안에 담겨요.

## 바코 오로라 조작법

화면은 프리미어 프로처럼 **프로젝트**(가져온 파일) · **프로그램 모니터** · **타임라인** · **효과 컨트롤**로 나뉘어요.
파일은 복사하지 않고 디스크의 원본을 가리켜요. 프로젝트는 `.bvid` 로 저장해요.

| 조작 | 동작 |
| --- | --- |
| 파일을 창에 끌어다 놓기, Ctrl+I | 가져오기 (mp4, webm, mov, png, jpg, mp3, wav …) |
| 프로젝트 칸에서 끌어서 트랙에 놓기 / 더블클릭 | 타임라인에 넣기 (덮어쓰기) |
| Space · J K L | 재생 / 멈춤 · 뒤로, 멈춤, 앞으로 (L 을 여러 번: 2배, 4배) |
| ← → (Shift: 5프레임) · ↑ ↓ · Home End | 한 프레임 · 앞/다음 편집점 · 처음/끝 |
| V · C | 선택 도구 · 자르기 도구 (Shift+클릭: 모든 트랙) |
| Ctrl+K | 재생 위치에서 자르기 |
| 클립 가장자리 끌기 | 앞뒤 다듬기 |
| Delete · Shift+Delete | 지우기 · 빈자리 당기며 지우기 |
| I · O · M | 내보낼 시작/끝 표시 · 마커 |
| S | 스냅 (재생 위치, 클립 끝, 마커에 착 붙기) |
| = - \\ · Ctrl+휠 | 타임라인 확대/축소/전체 보기 |
| Ctrl+D · Ctrl+T | 기본 전환(교차 디졸브, 앞 클립이 없으면 페이드) · 글자 넣기 |
| Ctrl+C / Ctrl+V | 클립 복사 / 재생 위치에 붙여넣기 |
| Ctrl+S · Ctrl+O · Ctrl+N | 프로젝트 저장 · 열기 · 새로 만들기 |
| Ctrl+M | 내보내기 (MP4 H.264 / WebM, 크기, 화질, I~O 범위) |
| F3 | 기능 검색 |

- **효과 컨트롤**: 위치, 크기, 회전, 불투명도, 볼륨에 ⏱ 를 켜면 키프레임으로 움직여요. 숫자는 좌우로 끌거나 눌러서 입력해요.
- **색 보정**: 밝기, 대비, 채도, 색온도, 색조, 비네트, 흐림과 한 번에 바꾸는 룩(따뜻하게, 영화처럼, 빈티지 …).
- **크리에이티브 룩 (LUT)**: 틸 앤 오렌지, 블리치 바이패스, 필름, 노을, 낮을 밤으로, 흑백 필름 같은 영화 색감을 강도와 함께 골라요. 다빈치 리졸브, 프리미어, 포토샵용 **.cube** LUT 파일도 가져와 쓸 수 있고, 프로젝트 파일에 같이 저장돼요.
- **조정 레이어**: ◐ 조정 버튼(클립 → 조정 레이어 넣기)으로 넣으면 아래 트랙에 보이는 모든 것에 색 보정과 LUT 이 한꺼번에 입혀져요. 길이를 늘려 여러 장면을 한 번에 보정하고, 크롭으로 화면 일부만, 불투명도로 세기를 조절해요.
- **루메트리 범위** (오른쪽 패널, 보기 메뉴에서 켜고 끄기): 프리미어의 Lumetri Scopes 처럼 파형, RGB 퍼레이드, 벡터스코프(피부색 선, 색 막대 목표점), 히스토그램으로 화면의 밝기와 색을 숫자로 확인해요. 하얗게 날아간 곳, 색이 한쪽으로 틀어진 것, 너무 진한 색을 눈대중이 아니라 그래프로 잡을 수 있어요. 재생 중에도 따라와요.
- **유튜브 챕터**: M 으로 마커를 넣고 두 번 눌러 이름을 붙인 뒤, 시퀀스 → "마커로 유튜브 챕터 만들기"를 누르면 `0:00 시작` 같은 챕터 목록이 복사돼요. 유튜브 설명란에 붙여 넣으면 영상에 챕터가 생겨요 (3개 이상, 10초 이상씩인지도 알려 줘요).
- **모션 트래킹**: 글자나 스티커 클립을 따라갈 물체 위에 올리고 클립 → "모션 트래킹"을 누르면, 프레임마다 물체를 찾아 위치 키프레임을 만들어 줘요. 얼굴 위 이름표, 공을 따라가는 화살표, 모자이크용 조정 레이어에 좋아요. 중간에 놓치면 그 자리부터 다시 하면 이어져요.
- **전환**: 왼쪽 **효과** 탭에서 교차 디졸브, 검게·하얗게 디핑, 밀어내기, 슬라이드, 와이프, 원형 열기, 줌, 흐림 전환을 끌어 뒤 클립에 놓아요. 앞 클립 원본의 뒷부분이 이어서 보이면서 넘어가요. 종류와 길이는 효과 컨트롤에서 바꿔요.
- **울트라 키**: 초록(파랑) 화면 앞에서 찍은 영상을 위 트랙에 두고 켜면 배경이 투명해져요. 💧 로 화면에서 배경색을 집고, 범위·가장자리·초록 빼기로 다듬어요.
- **자르기(크롭)**, **혼합 모드**(곱하기, 스크린, 오버레이 …), 글자 **등장 애니메이션**(타자기, 톡 튀어나오기, 아래서 올라오기, 옆에서 들어오기, 통통 튀기).
- **정확 내보내기**: 내보내기(Ctrl+M)에서 ‘정확하고 빠르게’ 형식(MP4 H.264 · WebM VP9)을 고르면, 화면을 녹화하지 않고 프레임을 하나씩 그려 바로 인코딩해요. 프리미어의 내보내기처럼 빠지는 프레임이 없고, 소리(볼륨 키프레임, 페이드, 속도, 음소거·솔로)는 따로 정확히 섞어 Opus 로 넣어요. 컴퓨터가 빠르면 영상 길이보다 빨리 끝나요. 예전 방식(실시간 녹화)도 남아 있어요.
- **자막 파일**: 파일 → 자막 가져오기(SRT)로 줄마다 글자 클립을 만들고, 자막 내보내기로 글자 클립을 SRT 로 저장해 유튜브에 올려요.
- 트랙마다 숨기기, 소리 끄기, 솔로, 잠그기가 있어요. 위 트랙의 영상이 앞에 보여요.
- 모니터에서 고른 클립을 끌어 위치를 옮길 수 있어요. **보기** 메뉴에서 안전 영역과 재생 화질(끊기면 1/2, 1/4)을 바꿔요.
- 20초마다 자동 저장해서, 갑자기 꺼져도 다음에 켤 때 되살릴 수 있어요.
- AI 도우미에게 "재밌는 자막 달아줘"처럼 쓰면 맨 위 영상 트랙에 글자 클립으로 자막을 넣어 줘요.

Home 은 처음 시점, **.** 은 선택한 오브젝트를 화면 가운데로 가져와요.

## G / R / S 로 움직이기 (블렌더식)

손잡이 없이 키 하나로 움직이는 방법이에요. 오브젝트 모드에서는 고른 오브젝트를, 편집 모드에서는 고른 점·선·면을 움직여요.

1. **G**(옮기기), **R**(돌리기), **S**(늘리기) 중 하나를 눌러요. 마우스를 움직이는 대로 따라와요.
2. 그 상태에서 **X / Y / Z** 를 누르면 그 방향으로만 움직여요. 한 번 더 누르면 풀려요.
3. 숫자를 치면 정확한 값이 들어가요. 예: `G` `Z` `2` → 위로 2칸, `R` `Y` `90` → Y축으로 90도, `S` `0.5` → 절반 크기.
4. 클릭이나 Enter 로 확정, 오른쪽 클릭이나 Esc 로 취소해요. Shift 를 누르고 움직이면 천천히, Ctrl 을 누르면 칸에 맞춰 움직여요.

## 매끈하게 (서브디비전)

블렌더의 서브디비전 표면처럼, 각진 도형을 둥글게 나눠서 보여 줘요. 정육면체에 2단계를 주면 조약돌처럼 돼요.

- 속성의 **매끈하게**에서 끔 / 1 / 2 / 3 을 고르거나 Ctrl+1~3 을 눌러요. 원래 점, 선, 면은 그대로라 언제든 끌 수 있어요.
- 편집 모드에서는 바깥에 원래 모양의 점과 선(케이지)이 보이고, 그 점을 움직이면 둥근 모양이 따라와요.
- 모서리를 더 각지게 하고 싶으면 그 근처에 **루프 컷**(Ctrl+R)으로 선을 하나 더 넣어요. 선이 촘촘할수록 그 부분이 덜 둥글어져요.
- **적용**을 누르면 지금 보이는 둥근 모양이 진짜 점, 선, 면이 돼요. 로블록스로 내보낼 때는 적용하지 않아도 보이는 모양 그대로 나가요.
- **면 잇기**에서 자동 / 모두 부드럽게 / 모두 각지게를 고를 수 있어요.

## 조각 모드 (스컬프트)

블렌더의 스컬프트 모드처럼 찰흙을 빚듯 붓으로 모양을 만들어요. 도형을 고르고 위쪽 **조각 모드**를 누르세요.

1. 오른쪽 **조각 붓** 칸에서 **⊞ 촘촘하게**를 몇 번 눌러 면을 늘려요 (정육면체는 5번, 면 6천 개쯤이면 곱게 빚어져요).
2. 모양 위를 끌면 칠해지고, 빈 곳을 끌면 화면이 돌아가요.

| 키 | 붓 | | 키 | 붓 |
| --- | --- | --- | --- | --- |
| X | 그리기 (부풀리며 칠하기) | | I | 부풀리기 |
| C | 찰흙 (평평하게 덧바르기) | | T | 평평하게 |
| S | 부드럽게 | | P | 모으기 (날카로운 선) |
| G | 잡아끌기 (뿔, 코, 귀 늘이기) | | Shift+C | 주름 (가는 홈) |

- **Ctrl** 을 누르고 칠하면 반대로(파기), **Shift** 를 누르고 칠하면 잠깐 부드럽게 붓이 돼요.
- **[ ]** 붓 크기, **Shift+[ ]** 세기. **좌우 대칭**을 켜 두면 얼굴, 몸을 한쪽만 칠해도 양쪽이 같이 빚어져요.
- 붓을 뗄 때마다 Ctrl+Z 로 한 번씩 되돌릴 수 있어요. Tab 을 누르면 조각 모드가 끝나요.

## 불리언 (합치기, 빼기)

로블록스의 Union, Negate 처럼 도형 두 개로 새 모양을 만들어요. 오브젝트를 고르면 오른쪽에 **불리언** 칸이 나와요.

- **대상**에서 함께 쓸 다른 오브젝트를 고르고 **합치기**, **빼기**(대상 모양만큼 파내기), **겹친 곳만** 중 하나를 눌러요.
- 쓴 대상 오브젝트는 없어져요. ‘대상 숨겨서 남겨 두기’를 켜면 숨겨 두고 다시 쓸 수 있어요.
- 결과는 진짜 점, 선, 면이라 Tab 으로 계속 고칠 수 있어요. 마음에 안 들면 Ctrl+Z.

## 가져오기 (Ctrl+I)

다른 프로그램에서 만든 GLB, glTF, OBJ, STL 모델을 지금 장면에 더해요. 조각마다 오브젝트가 되고, 바닥이 땅에 닿게 놓여요. 너무 크거나 작으면 2m 쯤으로 맞춰 줘요. 삼각형이 15만 개가 넘는 모델은 받지 않아요.

## 모디파이어 (대칭, 배열, 두께)

블렌더의 모디파이어처럼, 원래 모양은 그대로 두고 보이는 모양만 바꿔요. 속성의 **매끈하게** 아래에 있어요.

- **대칭 X / Y / Z**: 그 축의 가운데 면을 거울 삼아 반대편을 자동으로 만들어요. 편집 모드에서 반쪽을 지우고 한쪽만 고치면 다른 쪽이 그대로 따라와요. 가운데에 닿은 점은 하나로 붙어요.
- **배열**: 같은 모양을 개수만큼 X, Y, Z 방향으로 나란히 이어 붙여요. 계단, 울타리, 기둥 줄을 만들 때 좋아요.
- **두께**: 얇은 판이나 뚜껑 없는 모양에 두께를 줘요 (블렌더의 Solidify). 컵, 그릇, 벽, 옷, 머리카락 카드 만들 때 좋고, 열린 가장자리는 저절로 막혀서 3D 프린트도 돼요. 닫힌 모양에 쓰면 속이 빈 껍데기가 돼요.
- 순서는 대칭 → 배열 → 두께 → 매끈하게예요. **모디파이어 적용**을 누르면 보이는 모양이 진짜 점, 선, 면이 돼요.

## 비례 편집 (O)

편집 모드에서 **O** 를 누르면 켜져요. 점 하나를 G 로 옮기면 주변 점들이 거리에 따라 부드럽게 따라와서, 언덕이나 볼록한 모양을 쉽게 만들 수 있어요. 움직이는 동안 마우스 휠이나 PageUp / PageDown 으로 영향 범위(원)를 바꿔요.

## 애니메이션 (키프레임)

블렌더처럼 프레임마다 모습을 기록해 오브젝트를 움직여요. 아래쪽 **타임라인**에서 프레임을 끌어 넘겨요.

1. 오브젝트를 고르고 **I** 를 눌러 지금 모습을 키(◆)로 기록해요.
2. 다른 프레임으로 가서(←/→, 타임라인 클릭) 옮기거나 돌린 뒤 **I** 를 또 눌러요. 그 사이가 저절로 움직여요.
3. **Space** 로 재생해요. ↑/↓ 는 다음/앞 키, Shift+←/→ 는 처음/끝, Alt+I 는 키 지우기예요.

- 타임라인의 ◆ 를 끌면 키의 시간을 옮겨요. **이어 가기**로 부드럽게(천천히 출발·멈춤), 일정하게, 끊어서를 고를 수 있어요.
- **● 자동 키**를 켜 두면 옮기고 돌릴 때마다 키가 저절로 들어가요.
- FPS(12/24/30/60)와 끝 프레임을 바꿀 수 있어요.
- **GLB 로 내보내면 애니메이션도 함께 들어가서** 게임 엔진이나 다른 3D 프로그램에서 그대로 움직여요.
- **렌더(F12) → 🎬 애니메이션 영상 렌더**로 WebM 영상을 만들어요. 프레임마다 정확한 시간을 붙여서 느린 PC 에서도 빠지는 프레임 없이 제 속도로 나와요. 바코 오로라에 넣어 편집할 수 있어요.

## 렌더 (F12)

**렌더 → 이미지 렌더**(F12)를 누르면 격자와 손잡이를 빼고 깨끗한 그림을 만들어요. 1920×1080, 4K, 정사각형, 세로(쇼츠) 크기를 고를 수 있고, 투명 배경과 빛 번짐(블룸)을 켤 수 있어요. 두 배로 크게 그린 뒤 줄여서 테두리가 매끈해요. 미리 보고 PNG 로 저장해요.

## 좌우 대칭 복제

팔 하나를 만들고 **편집 → 좌우 대칭 복제**(Ctrl+M)를 누르면 가운데 선(X=0)을 거울 삼아 반대편에 뒤집힌 짝이 생겨요. 이름에 ‘왼’이 있으면 ‘오른’으로 바꿔 줘요.

## 자동 저장

저장하지 않은 작업은 20초마다 몰래 따로 적어 둬요. 정전이나 오류로 프로그램이 갑자기 꺼지면, 다음에 켤 때 그 작업을 다시 불러올지 물어봐요. 정상적으로 닫거나 저장하면 이 사본은 지워져요.

## 예제와 시점

- **파일 → 예제 열기**로 작은 집, 나무, 블록 캐릭터, 횃불, 마법 수정구를 바로 열 수 있어요. 모두 기본 도형으로만 만들어서, 장면 목록에서 하나씩 눌러 보면 어떻게 만들었는지 알 수 있어요.
- 화면 오른쪽 위 **방향 표시**(X, Y, Z 공)를 누르면 그쪽에서 똑바로 봐요. 끌면 화면이 돌아가요.
- 그 아래 **앞 / 옆 / 위** 버튼(숫자패드 1, 3, 7)으로도 똑바로 볼 수 있어요. **원근/평면** 버튼(숫자패드 5)은 멀리 있어도 같은 크기로 보이는 평면 보기로 바꿔서 치수를 맞추기 좋아요. ⌂ 는 처음 시점이에요.
- 아무것도 고르지 않고 **.** 키를 누르면 장면 전체가 화면에 들어와요.

## 겉면과 칸 맞춤

- 물체를 고르고 속성의 **겉면**에서 플라스틱, 흙·나무, 반들반들, 금속, 유리를 고를 수 있어요. 색은 그대로 두고 느낌만 바뀌어요.
- **Shift+Tab**(또는 보기 메뉴)으로 칸 맞춤을 켜면 이동은 0.25칸, 회전은 15도, 크기는 0.25씩 딱딱 맞춰 움직여요.
- 화면 맨 아래에 전체 삼각형 수가 나와요. 게임에 넣을 모델은 적을수록 가벼워요.

## 로블록스에 넣기

1. **파일 → 로블록스용으로 내보내기**로 `.glb` 파일을 저장해요. **(고른 것만)**을 쓰면 고른 오브젝트 하나만 저장해요. 오브젝트 하나가 로블록스에서 MeshPart 하나가 돼요.
2. 로블록스 스튜디오에서 **3D 가져오기(Import 3D)**로 그 파일을 열어요.
3. 로블록스는 메시 하나에 삼각형을 2만 개쯤까지만 받아요. 넘는 오브젝트가 있으면 내보내기 전에 알려 줘요.
4. 이펙트는 따라가지 않아요. 연기나 불꽃은 로블록스 안에서 ParticleEmitter 로 붙여 주세요. 움직이는 캐릭터(뼈대, 애니메이션)는 아직 못 만들어요.

## 이펙트

- **이펙트** 메뉴에서 연기, 반짝이, 불꽃, 눈, 마법, 거품을 추가할 수 있어요. 이동·크기 도구로 위치와 크기를 바꾸고, 오른쪽 속성에서 종류·양·속도를 조절해요.
- 물체를 고르고 속성의 **빛나기** 막대를 올리면 그 물체가 자기 색으로 빛나요.
- 빛 번짐이 무거우면 **보기 → 빛 번짐 끄기**로 끌 수 있어요.
- AI 도우미에게 "불타는 횃불 만들어줘"처럼 말해도 이펙트와 빛나기를 함께 써요.

## AI 도우미 쓰기

1. [console.anthropic.com](https://console.anthropic.com/settings/keys) 에서 API 키를 만듭니다 (사용한 만큼 요금이 나가요).
2. 허브 오른쪽 **AI 도우미** 칸이나, 각 프로그램 오른쪽 AI 도우미 패널의 **API 키 설정** 을 눌러 키를 붙여 넣습니다. 한 번 넣으면 모든 프로그램이 같이 써요. 키는 이 컴퓨터에만 암호화해서 저장돼요.
3. "빨간 지붕이 있는 작은 집" 처럼 만들고 싶은 것을 글로 쓰면 AI 가 도형을 조합해 만들어 줘요. "지붕을 더 높게" 처럼 이어서 고칠 수도 있고, 마음에 안 들면 Ctrl+Z 로 되돌리면 돼요.

AI 연결은 `packages/shell/src/ai.ts` 에 있고 제품군의 모든 앱이 같이 써요.
