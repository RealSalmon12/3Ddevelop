# 3Ddevelop

초보자도 쉽게 쓸 수 있는 크리에이티브 프로그램 제품군 **누구나 스튜디오**입니다.
어도비 제품군처럼 용도가 다른 여러 프로그램이 같은 디자인과 같은 AI 도우미를 함께 씁니다.
첫 번째 프로그램은 블렌더처럼 쓰는 **3D 모델러**입니다.

## 폴더 구조

```
apps/
  modeler/        3D 모델러 (Electron + React + three.js)
packages/
  shell/          모든 앱 공통 Electron 기반: 창 만들기, 화면과 메인 프로세스 연결, AI 요청 통로
  ui/             모든 앱 공통 화면 디자인: 테마, 메뉴 막대, 도구 막대, 패널, AI 도우미 패널
```

새 프로그램(예: 사진 편집기)은 `apps/` 아래에 폴더를 하나 더 만들고 `@suite/shell` 과 `@suite/ui` 를 가져다 쓰면 됩니다.
제품군 이름은 `packages/ui/src/brand.ts` 한 곳에서 바꿀 수 있습니다.

## Windows 에서 실행하기

1. [Node.js](https://nodejs.org/) LTS 버전(22 이상)을 설치합니다.
2. 이 폴더에서 명령 프롬프트나 PowerShell 을 열고 한 번만 실행합니다.
   ```
   npm install
   ```
3. 3D 모델러를 개발 모드로 켭니다. 코드를 고치면 화면이 바로 바뀝니다.
   ```
   npm run dev:modeler
   ```

그 밖의 명령:

| 명령 | 하는 일 |
| --- | --- |
| `npm run build:modeler` | 3D 모델러를 실행 파일로 묶기 전 단계까지 빌드 |
| `npm run typecheck` | 모든 패키지의 TypeScript 타입 검사 |

## 3D 모델러 조작법

| 조작 | 동작 |
| --- | --- |
| 왼쪽 드래그 / 휠 버튼 드래그 | 화면 돌려보기 |
| 오른쪽 드래그 | 화면 옮기기 |
| 마우스 휠 | 확대 / 축소 |
| 클릭 | 오브젝트 선택 |
| Q / W / E / R | 선택 / 이동 / 회전 / 크기 도구 |
| Delete 또는 X | 선택한 오브젝트 지우기 |
| Ctrl+D | 선택한 오브젝트 복제 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+N / Ctrl+O / Ctrl+S | 새로 만들기 / 열기 / 저장 (Ctrl+Shift+S: 다른 이름으로 저장) |
| Tab | 편집 모드 켜기/끄기 (점, 선, 면 고치기) |

편집 모드에서:

| 조작 | 동작 |
| --- | --- |
| 1 / 2 / 3 | 점 / 선 / 면 고르기 |
| 클릭, Shift+클릭 | 고르기, 여러 개 고르기 |
| A | 모두 고르기 / 모두 풀기 |
| Shift+E | 돌출 (고른 면을 밀어내기) |
| Shift+I | 안쪽 면 만들기 |
| M | 고른 점 합치기 |
| Delete | 고른 것 지우기 |

크기 도구로 한쪽 손잡이를 끌면 반대쪽은 제자리에 있고, 가운데 흰 상자를 끌면 바닥에 붙은 채로 커집니다.
| Home | 처음 시점으로 |
| . | 선택한 오브젝트를 가운데로 |
